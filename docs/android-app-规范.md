# Android App 规范（Flutter）

「短句」移动端。技术栈与目录见 `client-android/README.md`；本篇只定**设计语言、动效规范与本轮交付范围**。

## 一、定位

移动端不是 Web 端的缩小版。手机上单手操作、竖屏、频繁往返，因此：

- **信息密度更低**：一屏一件事，卡片化承载；
- **操作更靠近拇指**：主操作沉在下方，导航固定在底部；
- **动效承担状态说明**：翻卡、切 Tab、进度升温都不是装饰，而是「发生了什么」的反馈。

功能契约与 Web 端一致（同一套后端、同一套判定口径），**视觉与交互按移动端重做**。

## 二、本轮范围

对照 Web 端（`client-web/app/pages`）盘点，登录/注册与刷题主链路已完成，其余为缺口：

| 模块     | Web 端                   | 本轮交付                                       | 验收要点                                                                                                    |
| -------- | ------------------------ | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| App 外壳 | 顶部导航                 | **四 Tab 底栏**（刷题 / 语句库 / 成长 / 我的） | 切 Tab 有交叉淡入、指示器滑动、图标弹性；各页状态保留；底栏为**停靠式**（通栏贴底、方角、顶部细线，非悬浮） |
| 刷题     | ✅                       | 视觉与动效重做                                 | 流光 Hero、卡片层叠、输入聚焦光晕、XP 飘字、达标彩带                                                        |
| 语句库   | 收藏 / 复习 / 历史       | **新增**（三 Tab 合一）                        | 分页、下拉刷新、触底加载、滑动取消收藏（可撤销）、详情弹窗                                                  |
| 成长     | 成长面板（嵌在「我的」） | **独立页**                                     | 等级环、XP 进度、连续打卡、成就网格、场景地图、句签墙                                                       |

| AI 拓展  | 独立页（造句/词根/词典） | **卡片背面入口 + 弹窗**                        | 流式打字机、额度显示、用完置灰、可取消                                                                      |

## 三、设计语言

### 色彩

品牌沿用 `sky-500 → indigo-500 → violet-500` 渐变，但**大面积只用在中轴**（Hero、身份卡、句签），其余靠白卡与留白撑起层次，避免整屏渐变发甜。

| 语义 | 亮色      | 暗色      | 用途                             |
| ---- | --------- | --------- | -------------------------------- |
| 画布 | `#F5F7FB` | `#0A0E1A` | 页面底色（带一层极淡的品牌色雾） |
| 卡面 | `#FFFFFF` | `#141A2A` | 卡片、弹窗                       |
| 主文 | `#0F172A` | `#E8EDF7` | 标题、正文                       |
| 次文 | `#64748B` | `#8A97AC` | 说明、辅助                       |
| 主色 | `#0EA5E9` | `#38BDF8` | 强调、链接、聚焦                 |
| 成功 | `#10B981` | `#34D399` | 答对、已解锁                     |
| 失败 | `#F43F5E` | `#FB7185` | 答错、危险操作                   |
| 金   | `#F59E0B` | `#FBBF24` | 达标、连续打卡、句签             |

进度 Hero 的五档配色与 Web 端 `HERO_STAGES` 逐值一致（`theme/brand.dart`），三端观感统一；移动端额外叠加流动光带与呼吸光点。

### 形状与层次

- 圆角：卡片 24、弹窗 28、输入/按钮 16、标签 999；
- 阴影**两层**：`(0,1) blur 2, 6%` 贴边 + `(0,12) blur 28, 8%` 散开，比单层大阴影更干净；
- 描边 `1px` 用 `outlineVariant` 的 45%，让白卡在浅底上仍有边界。

### 字体层级

| 角色   | 字号 / 字重          | 场景             |
| ------ | -------------------- | ---------------- |
| 数字   | 34 / w700，`-1` 字距 | 进度、XP、统计   |
| 标题   | 20 / w700            | 页面标题、答案句 |
| 小标题 | 15 / w600            | 卡片标题、区块名 |
| 正文   | 14 / w400，行高 1.45 | 中文题干、说明   |
| 标签   | 11 / w500            | Pill、辅助信息   |

### 间距

`4 / 8 / 12 / 16 / 20 / 24 / 32` 七档，页面横向统一 16，卡片内 20。

## 四、动效规范

统一由 `lib/theme/motion.dart` 提供，禁止散落魔法数字。

| 令牌                | 值                        | 用途                                       |
| ------------------- | ------------------------- | ------------------------------------------ |
| `Motion.fast`       | 160ms                     | 按压、颜色、图标切换                       |
| `Motion.normal`     | 260ms                     | 卡面内容、Tab 切换、展开                   |
| `Motion.slow`       | 420ms                     | 页面进出、Hero 阶段过渡                    |
| `Motion.flip`       | 520ms                     | 翻卡（与 Web 端 450ms 同量级，稍慢更易读） |
| `Motion.standard`   | `Cubic(0.2,0,0,1)`        | 默认（M3 emphasized）                      |
| `Motion.decelerate` | `Cubic(0.05,0.7,0.1,1)`   | 入场                                       |
| `Motion.spring`     | `Cubic(0.34,1.56,0.64,1)` | 弹性反馈（词块、收藏、选中）               |

### 原则

1. **有因才有动**：动效必须对应一次状态变化，不做无触发源的循环动画（Hero 光带除外，它是「活着」的氛围，且极慢）。
2. **入快出慢**：入场 260ms 完成，退场 160ms，避免用户等动画。
3. **错峰不超过 330ms**：列表入场每项间隔 55ms，最多延迟 6 项，再长会显得卡。
4. **尊重减弱动效**：`MediaQuery.disableAnimations` 为真时，所有位移/缩放/循环动画降为瞬时，颜色仍平滑过渡。
5. **不加装饰性阴影动画**：阴影变化走 `AnimatedContainer` 的 `decoration` 插值，避免掉帧。

### 关键动效清单

| 场景       | 效果                                                       |
| ---------- | ---------------------------------------------------------- |
| 切 Tab     | 交叉淡入 + 1.5% 缩放回正（260ms），图标弹性放大 + 触感反馈 |
| 页面进出   | 右侧滑入 24px + 淡入（push）；返回反向                     |
| 刷题卡入场 | 从下方 18px 浮起 + 淡入，卡片背后的两层「叠片」错位 5/10px |
| 提交答案   | 卡片先微沉（0.985）再翻到背面；背面内容错峰浮现            |
| 判分结果   | 结果条从左侧滑入，经验值 `+N` 从底部浮起并淡出             |
| 达标       | 金橙 Hero 呼吸 + 彩带从顶部散落（2.2s，只播一次）          |
| 拼词       | 词块点选时缩到 0.92 再弹回；已选区新增词块从 0.8 弹入      |
| 收藏       | 星标放大 1.35 回弹，金色闪烁一次                           |
| 列表       | 每项 55ms 错峰上浮；加载更多用底部骨架三行                 |
| 骨架屏     | 微光从左向右扫过（1.4s 循环）                              |
| 升级/解锁  | 成就卡从 0.9 弹入 + 一次扫光                               |

## 五、页面结构

```
ShellPage（底部四 Tab，各页保留状态）
├─ 刷题：头部（问候 + 连续天数）→ 进度 Hero → 作答方式 → 翻转卡 → 辅助入口
│    └─ 达标后：领取句签入口 → 全屏句签**闪卡**（先卡背，轻触翻面看句子）
├─ 语句库：分段控件（收藏 / 复习 / 历史）→ 列表（下拉刷新 / 触底加载 / 滑动取消）
│    └─ 点条目：详情弹窗（配图 + 中英 + 音标 + 操作）
├─ 成长：身份 + 等级环 → 今日进度 → 成就墙 → 场景地图 → 句签墙
└─ 我的：身份卡 → 数据概览 → 菜单（编辑资料 / 修改密码 / 关于 / 退出）
     └─ 编辑资料、修改密码：底部弹窗
```

刷题卡背面另有「AI 拓展」「举报」入口，均为底部弹窗，不打断当前题。

## 六、验收标准

**功能**

- 四个 Tab 均可独立加载、刷新，失败有可重试的错误态；
- 收藏/复习/历史分页正确（触底加载无重复、无跳过），取消收藏后列表与总数同步；
- 句签：未达标不可领、已领取显示「已领取」、领取后出现在句签墙；
- 句签闪卡：打开先给卡背（日期 + 封蜡 + **寄语**），点一下翻面看句子与配图，
  再点可翻回；翻面落定扫过一道光；系统「减弱动效」时直接展开、不转；
  **没有翻面/收起按钮**：点卡片本身翻面，点弹窗空白处关闭（wire 网页端无此二按钮，
  移动端刻意不加——卡片是主体，Footer 上的小链容易误触）；
  **翻回不换方向**：翻面控制器值域 0~2，翻回是「继续转完下半圈」，观感是一张卡
  始终朝同一方向转，而不是正转半圈、倒转半圈；
- 资料保存后立即回显并同步本地缓存；改密成功后旧密码失效；
- AI 拓展流式输出逐字呈现，可中途取消，额度耗尽有明确提示。

**视觉**

- 亮/暗色均无低对比文字（正文对比度 ≥ 4.5:1）；
- 所有卡片圆角、阴影、间距来自令牌，无「这一页和那一页不一样」；
- 动效无跳帧：页面滚动、翻卡、切 Tab 目视流畅（模拟器 60fps）。

**稳定性**

- `flutter analyze` 零告警、`flutter test` 全绿；
- 断网、超时、401 三种异常均有兜底，不出现白屏或崩溃；
- 切 Tab / 进出页面不重复发请求（状态保留、有缓存）。

## 七、依赖策略

**本轮零新增运行时依赖**。彩带、微光、数字滚动、按压反馈、等级环全部自绘（`CustomPainter` / `AnimationController`），避免为几个视觉效果引入包并拉高体积。

## 八、实现备注（踩过的坑）

这几条都是「代码能编译、静态检查全绿，但运行时一定出问题」的类型，改相关代码前先看一眼。

1. **`INTERNET` 权限必须写在 `main/AndroidManifest.xml`**。
   Flutter 模板只把它放在 `debug/` 与 `profile/` 清单里（给工具链调试用），
   release 不会继承 —— 打出来的正式包所有网络请求直接失败，
   而拦截器当时又把网络错误伪装成成功响应，报的是「服务端返回格式异常」，极难定位。

2. **网络层错误必须以异常抛出**，不能 `handler.resolve` 伪造一个响应。
   否则调用方的 `_unwrap` 找不到 `data`，断网/超时会被报成「返回格式异常」。

3. **`TickerMode` 要放在 `AnimatedOpacity` 里面**。
   套在外面会把淡出动画自己的 Ticker 一起停掉，旧页面停在 `opacity=1`，
   切 Tab 时两页叠着显示（表现为「我的」页面上还能看到刷题页的按钮）。

4. **SSE 分片不能 `trim()`**。分片常以空格开头（`"...already"` + `" got"`），
   trim 会把词粘在一起，只含空格的片段甚至会被吞掉，JSON 结构随之破坏。

5. **`showGeneralDialog` 不提供 Material**。弹窗内容里的 `Text` 会落到
   `DefaultTextStyle.fallback()`（黄字 + 双下划线），看起来像一堆链接。
   句签海报这类全屏弹窗要自己包一层 `Material(type: MaterialType.transparency)`。

6. **无限循环动画会让 Widget 测试永远等不到静止**。
   极光与骨架微光受 `Motion.loopAnimations` 控制，测试里必须置 false。

7. **动画时长别只图快**：模拟器 debug 包首帧会掉 100+ 帧，看起来像卡死甚至触发 ANR；
   验证动效与截图用 `flutter run --release`，那才是真实表现。
8. **单向翻转要放开控制器上界**：`AnimationController` 默认 `upperBound: 1`，
   「翻回 = 继续转第二圈」的 `animateTo(2)` 会被钳成 1 —— 控制器动也不动，
   卡片像卡在正面。上界给到 2，落定后由 status 监听归一化回 0。
9. **`Curve.transform` 只接受 0~1**：值域 0~2 的控制器不能直接把 `1.38` 喂进曲线，
   框架会断言崩溃（翻回时必现）。按半圈分段喂：`v <= 1 ? curve(v) : 1 + curve(v - 1)`。
10. **翻面用「忙锁」而不是帧时间戳**：手势回调跑在帧外，
    `SchedulerBinding.currentFrameTimeStamp` 在这一步会直接断言「没有帧」。
    用 `Timer` 上锁（翻面 520 + 扫光 900 ms），它跟着测试假时钟走、
    `dispose` 里取消即可；忽视了取消，Widget 测试会以
    「A Timer is still pending」失败——框架对遗留定时器零容忍。
11. **测试里别用「一帧长跳」**：`tester.pump(duration)` 不会推进动画 ticker，
    看起来像「动画没跑」。推进动画要用 `pumpAndSettle()`（逐帧推进）。

## 九、性能约定

移动端的卡顿多半不是「代码慢」，而是**画了不该画的东西**或**解了不该解的图**。几条硬约定：

| 场景         | 约定                                                             | 原因                                                         |
| ------------ | ---------------------------------------------------------------- | ------------------------------------------------------------ |
| 列表缩略图   | `CachedNetworkImage` 必须给 `memCacheWidth`（按显示宽 × 3 倍屏） | 原图 1280px，56dp 的缩略图按原尺寸解码，一张就吃掉几 MB 内存 |
| 持续动画区域 | 外加 `RepaintBoundary`（进度 Hero、翻卡、每个 Tab）              | 柔光/翻转每帧重绘，不隔离会把整段列表一起标记为脏            |
| 列表入场动画 | 只给前 8 项做错峰，其余直接显示                                  | 滚动回收后重建会重播动画，看起来像页面在抖，还反复创建控制器 |
| 装饰性背景   | 用径向渐变画柔光，不用 `ImageFilter.blur`                        | 模糊滤镜在滚动时反复重绘整层，径向渐变由 GPU 直接插值        |
| 图片占位     | 骨架屏用 `ShimmerBox`，可传 `animate: false` 静态化              | 骨架只在首屏短暂出现，不值得为它开一堆循环控制器             |

对应实现：`widgets/staggered.dart` 的 `_animateLimit`、`widgets/aurora.dart` 的径向柔光、
`quiz_page.dart` 的 RepaintBoundary，以及 `sentence_tile.dart` / `growth_page.dart` /
`profile_page.dart` 里的 `memCacheWidth`。

## 十、句签卡片：跨端同款

句签是**标志性元素，两端必须长得一样**。手机端 `sheets/sentence_card_sheet.dart`
与网页端 `client-web/app/components/SentenceCard.vue` 的结构、色板、文案一一对应：

| 网页端                                                                      | 手机端                                       |
| --------------------------------------------------------------------------- | -------------------------------------------- |
| 配图块 `rounded-3xl` + `ring-amber-200/60` + `shadow-xl`                    | 圆角 28 + `#FDE68A` 60% 细环 + 投影          |
| 句子压在配图上，底部 `h-2/3` 黑渐隐                                         | 同样压在图上，蒙版 stops `0 → 1/3 → 1` 等价  |
| 徽标：白底琥珀字「今日句签 · 已获得」+ 黑底白字「10月23日」                 | 同一句话、同一配色；日期同样显示成「M月D日」 |
| 文案：中文标题 18 粗体 + 英文标题 12 白 70% + 句子 16 半粗 + 译文 14 白 80% | 同字号同色                                   |
| 卡脚：白底、琥珀字、彩带图标、「完成今日目标，收下这张属于你的闪卡」        | 原文照搬                                     |
| `translateZ` 分层：徽标 30 / 文字 45 / 卡脚 20 / 高光 8                     | 徽标 z=18、封蜡 z=26（文字不抬，保清晰）     |

手机端只额外做三件事：翻开前的**卡背**（轻触揭晓）、用设备姿态代替鼠标、
以及弹窗必须的「翻面 / 收起」文字链（网页端是内嵌卡片，没有这两个按钮）。

色板取网页端的 Tailwind 值：amber-600 `#D97706`、amber-200 `#FDE68A`、
slate-100 `#F1F5F9`、slate-400 `#94A3B8`、slate-500 `#64748B`、slate-800 `#1E293B`。

## 十一、句签卡片的 3D 视差

网页端（`client-web/app/components/SentenceCard.vue`）靠**鼠标位置**驱动：整卡倾斜 ±8°、
日期/文字/页脚按 `translateZ` 分层、高光圆心跟随指针、配图上叠一层镭射。

手机上照搬不了指针，于是把驱动源换成**设备姿态**——数学上是同一件事（相对视角的偏移）。

| 项       | 取值                             | 说明                                           |
| -------- | -------------------------------- | ---------------------------------------------- |
| 透视焦距 | `setEntry(3, 2, 0.0011)` ≈ 900px | 网页端 1000px；再小边缘会被拉变形              |
| 最大倾角 | ±8°                              | 与网页端一致                                   |
| 跟手系数 | `follow = 0.16`                  | 50Hz 下约 100ms 时间常数，观感是「轻轻跟上来」 |
| 满偏角度 | `maxAngle = 0.30 rad` ≈ 17°      | 再小太灵敏（手抖都在晃），再大要转很久         |
| 死区     | 0.2°                             | 手机平放桌上时不持续唤醒上层重绘               |

实现要点：

- **姿态源用 `GAME_ROTATION_VECTOR`**，不用加速度计：加速度计只感知重力方向，
  手机像转方向盘那样左右转时读数完全不变，而那恰恰是看卡片最自然的动作。
  选 `GAME_` 而不是 `ROTATION_VECTOR`：不依赖磁力计，也不会被桌上的金属带跑。
- **原生侧只发原始四元数**，变换全在 Dart（`state/tilt.dart`）：调参不用重编 Android，
  而且这段数学是纯函数，能写单测（`test/tilt_test.dart`）。
- **不要走欧拉角**：`SensorManager.getOrientation` 是 ZYX 分解，在俯仰 ±90° 处奇异，
  而人举着手机看屏幕时俯仰角正在 -90° 附近——偏航与滚转会被耦合，
  表现是「卡片乱跳」，且换个姿势才复现。用 `qRel = qBase⁻¹ · qNow` 再转轴角，无奇异点。
- 轴角 → 卡片的映射：绕竖直轴左右转取**负号**（观感是「卡片留在原地，是你在绕它看」；
  正号会让卡片跟着屏幕一起转，等于看不出视差）。
- 高光**自成一层 `RepaintBoundary`**：姿态 50Hz 刷新时只重绘这块渐变，
  不会把配图与文字重新栅格化。
- 切到后台/关掉弹窗即取消订阅；**取消订阅时把偏移归零**，
  否则下一次打开卡片会「歪着醒来」（基准是重开的，残留值不会）。
- 没有传感器、系统开了「减弱动效」、或跑在桌面/测试环境时：**保持静止**。
  卡片照常能看，只是不跟着动——不是错误态，不弹提示。
